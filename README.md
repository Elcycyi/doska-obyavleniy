# Доска объявлений

Домашнее задание по курсу «Веб-технологии» (WIN-1-25).
Фронтенд к готовому REST API: список объявлений и форма подачи.

## Что делает

- **GET `/ads`** — забирает список объявлений и рисует карточками.
- **POST `/ads`** — отправляет новое объявление вместе с фотографией
  (`multipart/form-data`).

Обе части на одной странице, переключаются вкладками.

## Запуск

Страница статическая, сборка не нужна.

```bash
python3 -m http.server 8080
```

Затем открыть <http://localhost:8080>.

Открывать `index.html` двойным кликом (через `file://`) **нельзя** —
браузер заблокирует запросы к API.

## Файлы

| Файл | Назначение |
|------|------------|
| `index.html` | разметка: вкладки, сетка карточек, форма |
| `css/style.css` | оформление карточки и рамки под фото |
| `js/app.js` | запросы к API, отрисовка, валидация, предпросмотр |

## API

Базовый адрес: `https://inai-col1.fishrungames.com`

Поля формы при отправке: `title`, `description`, `price`, `image`.

Поле `image_url` в ответе приходит без домена (`/uploads/…`), поэтому
в коде оно склеивается с базовым адресом.
